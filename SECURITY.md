# Security policy

This policy covers every Nymra repository on GitHub (`github.com/nymrasi`) that does not have its
own `SECURITY.md`, plus the website, the Terminal, the docs and the Telegram helper bot
@nymrasi_bot.

## Report a vulnerability

Write to **contact@nymra.si**. Please include:

- what you found and where (repository and file, or the page and URL path);
- how to reproduce it;
- what an attacker could do with it.

Do not open a public issue, pull request or discussion for a security problem. If GitHub offers
"Report a vulnerability" on the repository's Security tab, you can use that instead; it stays
private.

## What to expect

- We confirm that we received your report as soon as we can.
- We keep you informed while we fix it, and we credit you in the fix if you want to be credited.
- Please wait until the fix is out before you talk about it in public.

## Rules for testing

- Only test with addresses and data that are yours or public.
- Do not run a denial of service, send spam or try social engineering on the team or the community.
- Never send funds or sign anything as part of a test. Nymra itself never needs either.

## Impersonation

Nobody at Nymra will ever ask you for a recovery phrase or a private key, or ask you to sign or
approve anything, and an admin never writes to you first. Report impersonators to contact@nymra.si
with a link or a screenshot.
